# Research Metrics

## Search Quality

- Best fitness / validation accuracy  
- Evaluations to target  
- Area under improvement curve  
- Diversity \(\hat\delta\) trajectories (SAPSO)

## Adaptation Explainability

- \(w^{(t)}, c_1^{(t)}, c_2^{(t)}\) traces  
- Adaptive phase occupancy  
- Stagnation recovery events  

## Lifecycle

- Optimization trigger precision/recall (vs injected drift)  
- Accept / reject rates  
- Time between observe→decision→optimize  

## Continuous Learning

- PSI / KS magnitudes  
- Recommendation distribution (`HOLD`/`RETRAIN`/`OPTIMIZE`)  
- Version lineage depth  

## Efficiency

- Wall-clock, evaluations, artifact size
