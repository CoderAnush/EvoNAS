# Demo Flow — EvoNAS v1.0.0

```text
Problem: static models degrade / one-shot NAS ends too early
        ↓
Show platform identity (version, doctor, Clean Architecture one-liner)
        ↓
Mock optimize (SAPSO) — adaptation without NN training
        ↓
simulate-loop — policy decisions + artifacts
        ↓
benchmark suite — fair PSO vs SAPSO vs Random Search
        ↓
Dashboard / API — ops surface
        ↓
Honest research beat (Phase 12A ranks) + paper/ pointer
```

## Success criteria

- [ ] Audience understands product ≠ “just PSO”
- [ ] Live command produces artifacts
- [ ] No invented neural accuracy claims
- [ ] Q&A can cite `paper/` and `artifacts/research/`
