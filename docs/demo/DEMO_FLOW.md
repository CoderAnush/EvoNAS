# Demo Flow

```text
Problem (static models degrade)
        ↓
EvoNAS observes + versions data (Phase 7)
        ↓
Decision Engine authorizes search (Phase 6)
        ↓
SAPSO redesigns architecture (Phase 5)
        ↓
Train / evaluate / validate
        ↓
Local promote or reject (no cloud deploy yet)
        ↓
Artifacts + replayable history
```

## Live Narrative Beats

1. **Show CLI help** — platform, not a single script.  
2. **Toy dataset** — reproducibility via checksums.  
3. **Mock PSO vs SAPSO** — adaptation is explainable, not random.  
4. **simulate-loop** — lifecycle states + decisions JSONL.  
5. **learn** — recommendations only; Decision Engine still decides.  
6. **Open artifacts** — science-grade audit trail.
