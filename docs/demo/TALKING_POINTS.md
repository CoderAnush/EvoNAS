# Talking Points

1. **EvoNAS is an AI lifecycle platform** — NAS is one capability inside observe→decide→optimize→validate→promote.  
2. **SAPSO is the production search engine** — Standard PSO remains for ablation.  
3. **Adaptation is deterministic** — diversity / improvement / stagnation drive \(w,c_1,c_2\).  
4. **DecisionEngine is the brain** — Continuous Learning only recommends.  
5. **Reproducibility first** — checksums, manifests, decision JSONL, replay hooks.  
6. **Clean Architecture** — domain free of frameworks; ports enable future backends.  
7. **What is missing on purpose** — cloud deploy, dashboard, registry (Phase 8+).  
8. **Research angle** — continuous architecture evolution under audited autonomy.
