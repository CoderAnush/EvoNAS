Getting Started

git clone https://github.com/CoderAnush/EvoNAS.git
cd EvoNAS
python -m venv .venv
pip install -e ".[dev]"
evonas version
evonas optimize --config configs/pso/adaptive_mock.yaml --dry-run

Full guide: docs/guides/QUICK_START.md

Ops UI: pip install -e ".[api,dashboard]" && evonas serve --demo
